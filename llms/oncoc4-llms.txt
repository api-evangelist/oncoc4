# OncoC4

> OncoC4, Inc. is a privately held, late clinical-stage biopharmaceutical company in Rockville, Maryland (founded 2020) developing novel biologics for cancer across the CTLA-4, CD24, PD-1/VEGF and Siglec immune-checkpoint pathways. Its lead candidate is gotistobart (BNT316/ONC-392), a next-generation anti-CTLA-4 antibody co-developed with BioNTech. OncoC4 publishes no public API, SDK, developer portal or developer documentation.

## API surface

OncoC4 has no developer program. There is no public API, no OpenAPI or AsyncAPI
description, no GraphQL endpoint, no MCP server, no A2A agent card, no SDK in any
package registry (npm, PyPI, RubyGems, crates.io, NuGet, Packagist all return zero
results for "oncoc4"), and no GitHub organization. The subdomains api.oncoc4.com,
developer.oncoc4.com and docs.oncoc4.com do not resolve.

The only machine-readable endpoints served on oncoc4.com are Umbraco CMS defaults
for website member authentication, not an API product:

- [OpenID Connect discovery](https://oncoc4.com/.well-known/openid-configuration): OAuth 2.0 / OIDC metadata for the Umbraco Delivery API member authorization server.
- [OAuth 2.0 authorization server metadata](https://oncoc4.com/.well-known/oauth-authorization-server): RFC 8414 document, byte-identical to the OIDC one.
- [JWKS](https://oncoc4.com/.well-known/jwks): RS256 public signing keys.

The endpoints those documents advertise live under `/umbraco/`, which
https://oncoc4.com/robots.txt disallows.
